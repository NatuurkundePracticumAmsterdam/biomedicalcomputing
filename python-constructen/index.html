    Python-constructen¶

    In deze appendix vind je een overzicht van de Python-constructen die in de module Biomedical Computing aan bod komen. Per construct staat een korte uitleg en een voorbeeld, soms aangevuld met een toelichting. De appendix is bedoeld als naslagwerk. Als je iets wilt teruglezen of opzoeken, dan ben je hier aan het juiste adres.

    Wil je meer weten over een Python-construct? Of wil je meer leren over Python? In Think Python van Allen B. Downey vind je uitgebreidere uitleg en extra oefeningen. Het boek is een goed startpunt en is gratis beschikbaar op https://allendowney.github.io/ThinkPython/.

    Commentaar¶

    Goede code is leesbaar, voor jezelf als je er later naar terugkijkt en voor anderen die ermee werken. Commentaar helpt daarbij. Commentaar is tekst die uitlegt wat de code doet, maar door Python negeert wordt. Je schrijft commentaar met een #. Alles wat na het # op dezelfde regel staat, wordt door Python genegeerd.

    Je kunt commentaar achter een regel code plaatsen, bijvoorbeeld om de eenheid van een grootheid aan te geven: 

    heart_rate = 72  # beats per minute
    Ook kun je commentaar op een eigen regel plaatsen, vóór de code waar het bij hoort: 
    # convert hours to seconds
seconds = hours * 3600
    Meerdere opeenvolgende commentaarregels zijn ook mogelijk: 
    # calculate BMI
# weight in kg; height in m
bmi = weight / height**2

    Niet elke regel code heeft commentaar nodig. Gebruik commentaar daar waar de code zelf niet meteen duidelijk maakt wat er gebeurt of hoe iets werkt. Duidelijke variabelenamen, zoals heart_rate, maken commentaar vaak overbodig.

    Variabelen¶

    Een variabele is een naam waaronder je een waarde opslaat. Je maakt een variabele aan door een naam te kiezen, een = te schrijven en daarna de waarde te geven. 

    age = 18
    Nu je de variabele age hebt aangemaakt, kun je de naam age gebruiken in je code. Python onthoudt welke waarde de variabele heeft.

    Je kunt de waarde van een variabele ook later aanpassen, dan overschrijf je de oude waarde. 

    age = 18
age = 19
    Na de tweede regel heeft age de waarde 19. De waarde 18 is overschreven.

    Kies altijd een duidelijke, beschrijvende naam voor een variabele. Gebruik bij namen met meerdere woorden een underscore als verbinding, dit heet snake_case. Een naam als age of blood_pressure maakt meteen duidelijk wat de variabele bevat. Een naam als x of a (meestal) niet. Een variabelenaam mag niet beginnen met een cijfer en mag geen spaties bevatten. 01patient en blood pressure zijn dus geen goede namen, patient01 en blood_pressure wel.

    Datatypes¶

    Python kent verschillende datatypes. Een datatype bepaalt wat voor soort waarde een variabele bevat en daarmee ook wat Python ermee kan doen. Zo betekent + afhankelijk van het datatype iets anders: 2 + 2 is optellen en geeft 4, terwijl "2" + "2" samenvoegen is en "22" geeft. Pas je een bewerking toe op een datatype waar die niet voor bedoeld is, zoals "2" + 2, dan geeft Python een foutmelding.

    String¶

    Een string (str) is een stuk tekst. Dat kunnen letters zijn, maar ook cijfers of een combinatie. Je schrijft een string altijd tussen aanhalingstekens. 

    module = "BMC"
patient_id = "042"

    Integer¶

    Een integer (int) is een geheel getal, zonder decimalen. Het kan zowel een positief als een negatief getal zijn. 

    year = 2026
temperature_change = -2  # degrees Celsius

    Float¶

    Een float (float) is een decimaal getal. Het kan zowel een positief als negatief decimaal getal zijn. Let op: ook een geheel getal met een decimaal punt is een float. 

    height = 1.83  # meter
freezing_point = 0.0  # degrees Celsius

    Boolean¶

    Een boolean (bool) bevat één van de volgende twee waarden: True of False. Je komt booleans vooral tegen als resultaat van een vergelijking:

    • 6 > 2 geeft True
    • 6 < 2 geeft False

    Je kunt een boolean ook rechtstreeks toekennen aan een variabele. Let op: True en False schrijf je altijd met een hoofdletter.

    Datatypes omzetten¶

    Je kunt een waarde van het ene datatype omzetten naar een ander datatype. Dit doe je met str(), int() en float(): 

    int("42")  # string to integer: 42
float("3.14")  # string to float: 3.14
str(29)  # integer to string: "29"
    Dit komt bijvoorbeeld van pas bij input(), omdat de invoer van de gebruiker dan altijd een string is.

    Omzetten naar boolean

    Je kunt een waarde ook omzetten naar een boolean met bool(). Getallen zijn False als ze nul zijn en True als ze een andere waarden hebben. Voor strings geldt: een lege string is False en een string met inhoud is True. 

    bool(0)  # False
bool(42)  # True
bool("")  # False
bool("text")  # True

    print()¶

    Met print() geef je Python de opdracht iets in de terminal te tonen. Wat je tussen haakjes zet, verschijnt als tekst op het scherm. 

    print("Hello, world!")
print(42)
    geven als uitvoer Hello, world! en 42. De aanhalingstekens om "Hello, world!" zie je in de uitvoer niet terug, die geven alleen aan dat het hier om tekst gaat.

    Je kunt ook variabelen printen in de terminal: 

    blood_sugar = 5.4  # mmol/L
print(blood_sugar)
    Python print dan de waarde die in de variabele is opgeslagen, niet de naam van de variabele. In dit geval dus 5.4.

    Je kunt meerdere waarden meegeven door ze te scheiden met een komma. Python voegt automatisch een spatie in tussen de waarden. 

    name = "Alice"
print("Hello", name)
    Dit geeft als uitvoer Hello Alice.

    f-strings

    Met een f-string heb je meer controle over de opmaak van je uitvoer. Bij een f-string schrijf je een f voor de aanhalingstekens en zet je variabelenamen tussen accolades: 

    name = "Anna"
blood_sugar = 5.4  # mmol/L
print(f"Patient {name} has a blood sugar of {blood_sugar} mmol/L.")
    Dit geeft als uitvoer Patient Anna has a blood sugar of 5.4 mmol/L. F-strings zijn handig als je tekst en variabelen wilt combineren tot een leesbare zin in je code.

    Je kunt binnen een f-string ook {variable=} schrijven. In de terminal print Python dan zowel de variabelenaam als de waarde: 

    blood_sugar = 5.4  # mmol/L
print(f"{blood_sugar=}")
    Dit geeft als uitvoer blood_sugar=5.4. Handig als je meerdere variabelen print en wilt weten welke waarde bij welke variabele hoort.

    input()¶

    Met input() kun je de gebruiker iets laten typen in de terminal. Gebruik input() als je programma invoer van de gebruiker nodig heeft. Die invoer sla je op in een variabele, zodat je er later in het programma iets mee kunt doen. 

    medication = input("Which medication did the patient receive? ")
print("Medication administered:", medication)
    Wat je tussen haakjes zet, verschijnt als tekst in de terminal. Daar achter typt de gebruiker zijn invoer.

    De invoer van de gebruiker is altijd een string. Wil je er een berekening mee doen, dan zet je de invoer eerst om naar een integer of een float: 

    dose = int(input("What is the dose in mg? "))
weight = float(input("What is the patient's weight in kg? "))

    Operatoren¶

    Operatoren zijn symbolen waarmee je een bewerking uitvoert op een of meer waarden. Python heeft onder andere operatoren voor berekeningen en voor het vergelijken van waarden.

    Rekenkundige operatoren¶

    Met rekenkundige operatoren doe je wiskundige berekeningen.

    • + voor optellen: 6 + 2 geeft 8
    • - voor aftrekken: 6 - 2 geeft 4
    • * voor vermenigvuldigen: 6 * 2 geeft 12
    • / voor delen: 6 / 2 geeft 3
    • ** voor machtsverheffen: 6**2 geeft 36

    Naast de mogelijkheid om waarden op elkaar te delen, heeft Python ook twee andere operatoren die samenhangen met de deling:

    • // voor het gehele deel van een deling: 7 // 2 geeft 3
    • % voor de rest na deling: 7 % 2 geeft 1
    Toewijzingsoperatoren

    Je hebt de toewijzingsoperator = al gezien bij variabelen. Er zijn ook verkorte notaties die een bewerking en toewijzing combineren:

    • +=: x += 2 is hetzelfde als x = x + 2
    • -=: x -= 2 is hetzelfde als x = x - 2
    • *=: x *= 2 is hetzelfde als x = x * 2
    • /=: x /= 2 is hetzelfde als x = x / 2

    Vergelijkingsoperatoren¶

    Met vergelijkingsoperatoren vergelijk je twee waarden. Het resultaat is altijd True (waar) of False (niet waar). Python kent de volgende vergelijkingsoperatoren:

    • == voor gelijk aan: 6 == 6 geeft True
    • != voor ongelijk aan: 6 != 2 geeft True
    • < voor kleiner dan: 6 < 2 geeft False
    • > voor groter dan: 6 > 2 geeft True
    • <= voor kleiner dan of gelijk aan: 6 <= 2 geeft False
    • >= voor groter dan of gelijk aan: 6 >= 6 geeft True

    Let op: == vergelijkt twee waarden, terwijl = een waarde toekent aan een variabele.

    Logische operatoren

    Bij if-statements en loops wil je soms meerdere voorwaarden combineren. Je kunt dan de volgende logische operatoren gebruiken:

    • and: beide voorwaarden moeten waar zijn
    • or: minstens één voorwaarde moet waar zijn
    • not: keert een boolean om, dus True wordt False en andersom

    Je kunt je code ook schrijven zonder logische operatoren, de code is dan alleen wat langer. Hieronder een voorbeeld zonder logische operatoren: 

    if age >= 18:
    if age <= 67:
        print("working age")
    Hetzelfde kun je korter schrijven met and: 
    if age >= 18 and age <= 67:
    print("working age")

    if-statements¶

    In een programma wil je soms specifieke acties uitvoeren afhankelijk van een voorwaarde. Stel dat je een lichaamstemperatuur uitleest: is de temperatuur te hoog, dan wil je een waarschuwing geven en is de temperatuur normaal, dan niet. Met een if-statement kun je dit programmeren: 

    if temperature > 38:
    print("fever")
    Python voert de code in het blok onder if alleen uit als de voorwaarde waar is, dus als de temperatuur hoger dan 38 graden Celsius is. Let erop dat de code is ingesprongen met vier spaties, zodat duidelijk is welke code bij de voorwaarde hoort.

    Als je ook iets wilt doen wanneer de voorwaarde niet waar is, dan gebruik je else: 

    if temperature > 38:
    print("fever")
else:
    print("normal temperature")

    Heb je meerdere voorwaarden, dan gebruik je elif. Python controleert de voorwaarden van boven naar beneden en voert het blok code uit behorende bij de eerste voorwaarde die waar is. 

    if temperature < 36:
    print("temperature too low")
elif temperature <= 38:
    print("normal temperature")
else:
    print("fever")

    Soms wil je een voorwaarde verder opdelen. Dat kan met geneste if-statements, een if-statement binnen een if-statement. 

    if temperature >= 36:
    if temperature <= 38:
        print("normal temperature")
    Geneste if-statements kun je korter schrijven met logische operatoren.

    Een variabele als voorwaarde

    Je hebt gezien dat een voorwaarde in een if-statement iets vergelijkt, zoals temperature > 38. Deze voorwaarde is waar of niet waar. Maar soms is een variabele zelf al True of False. In dat geval kun je de vergelijking weglaten. Een voorbeeld: 

    if is_raining == True:
    print("bring an umbrella")
    Dit kun je ook schrijven als: 
    if is_raining:
    print("bring an umbrella")
    Beide doen hetzelfde, maar de kortere versie is gebruikelijker in Python.

    Loops¶

    Met een loop voer je dezelfde code meerdere keren uit. Dat is handig als je een bewerking wilt herhalen zonder de code steeds opnieuw te schrijven. Python heeft twee soorten loops: de for-loop en de while-loop. Gebruik een for-loop als je van tevoren weet hoe vaak je iets wilt herhalen, bijvoorbeeld een vast aantal keer of voor elk karakter in een string. Gebruik een while-loop als je vooraf nog niet weet hoe vaak je iets wilt herhalen. Je herhaalt dan net zolang totdat een bepaalde voorwaarde niet meer geldt.

    for-loop¶

    Met een for-loop herhaal je code een vast aantal keren. De loop doorloopt een reeks, bijvoorbeeld een string, een reeks getallen of een lijst, en voert voor elk element in de reeks de code in de loop uit. 

    dna = "ATCG"

for base in dna:
    print(base)
    De variabele base krijgt bij elke herhaling de waarde van het volgende element in de reeks. Dus eerst A, daarna T, enzovoorts. In dit geval wordt de code vier keer herhaald en worden A, T, C en G onder elkaar in de terminal geprint. De code die herhaald wordt, staat ingesprongen onder de regel met for.

    Itereren met range()¶

    Met range() maak je een reeks getallen. Dat is handig als je een loop een bepaald aantal keren wilt herhalen. 

    for i in range(5):
    print(i)
    De variabele iis hier de zogeheten loopvariabele en krijgt bij elke herhaling de waarde van het volgende getal in de reeks. De naam van de loopvariabele kies je bij voorkeur passend bij wat de variabele voorstelt, bij een teller is i een gangbare keuze. range() begint standaard bij 0 en telt op tot, maar niet inclusief, het opgegeven getal. De code hierboven print dus 0, 1, 2, 3 en 4 onder elkaar in de terminal. Je kan ook een begin- en eindwaarde opgeven: 
    for i in range(2, 6):
    print(i)
    Nu worden de getallen 2, 3, 4, en 5 onder elkaar in de terminal geprint.

    Weggooivariabele

    Soms gebruik je een for-loop puur om iets een aantal keer te herhalen, zonder dat je de loopvariabele zelf nodig hebt. In dat geval is het een gangbare conventie om _ als naam te kiezen. Dat is een signaal aan de lezer dat de variabele bewust niet gebruikt wordt. 

    for _ in range(5):
    print("Hello!")
    Dit print vijf keer Hello! in de terminal.

    Indexeren met range(len(...))¶

    Eerder doorliep je de string dna direct met een for-loop. Soms wil je niet alleen elk element doorlopen, maar ook weten op welke positie dat element staat. Daarvoor combineer je range() met len(). 

    dna = "ATCG"

for i in range(len(dna)):
    print(i)
    len(dna) geeft de lengte van de string terug, in dit geval 4. range(len(dna)) maakt dan de reeks 0, 1, 2 en 3 en deze getallen worden onder elkaar in de terminal geprint. Je krijgt dus de positie van de basen in de string terug.

    Met de positie kun je ook het bijbehorende element opvragen. Dit heet indexering: je gebruikt een getal, de index, om een specifiek element op te vragen. 

    dna = "ATCG"

for i in range(len(dna)):
    print(dna[i])
    dna[i] geeft het element op positie i. Python telt posities vanaf 0, dus dna[0] is A, dna[1] is T, enzovoorts. De kracht van indexering zit in het combineren van de positie en het element: je weet niet alleen wat er op een positie staat, maar ook waar. 
    dna = "ATCG"

for i in range(len(dna)):
    print(i, dna[i])

    while-loop¶

    Met een while-loop herhaal je een blok code zolang een bepaalde voorwaarde geldt. 

    number = 120

while number > 100:
    print(number)
    number = number - 10
    De variabele number begint op 120. Bij elke herhaling controleert de loop of number > 100 nog steeds True is. Als dat zo is, dan wordt de waarde van number in de terminal geprint en daarna met 10 verlaagd. Zodra number de waarde 100 bereikt, stopt de loop.

    Het is belangrijk dat de voorwaarde van de while-loop uiteindelijk False wordt, anders stopt de loop nooit. Een loop die voor altijd draait, heet een oneindige loop. Als je per ongeluk een oneindige loop hebt gestart, dan kun je het programma onderbreken met de sneltoetscombinatie Ctrl+C (Windows) / Cmd+C (macOS) in de terminal.

    while-loop onderbreken met break¶

    Soms hangt de stopconditie af van iets wat pas tijdens de loop bekend wordt, bijvoorbeeld gebruikersinvoer. In dat geval start je een loop met while True:: de voorwaarde is altijd True, dus de loop draait in principe oneindig. Met break onderbreek je de loop wanneer jij dat wilt. 

    while True:
    resistance = float(input("Enter the resistance (Ohm): "))
    print("Recorded resistance (Ohm)", resistance)

    last_measurement = input("Was this the last measurement? (yes/no) ")
    if last_measurement == "yes":
        break
    Deze loop blijft metingen registreren totdat de gebruiker aangeeft dat de laatste meting is ingevoerd.

    Modules importeren¶

    Python bevat een aantal ingebouwde functies, zoals print() en input(), maar lang niet alle functies zijn in Python standaard beschikbaar. Extra functionaliteit kun je toevoegen door gebruik te maken van modules. Dit zijn bestanden met kant-en-klare functies die je kunt importeren. Sommige modules worden meegeleverd met Python, zoals pathlib en math. Andere, zoals matplotlib en sounddevice, moet je eerst installeren in je virtual environment.

    Met import laad je een module in je script. Daarna gebruik je de naam van de module gevolgd door een punt om functies aan te roepen. In het voorbeeld hieronder wordt de functie Path aangeroepen van de module pathlib: 

    import pathlib

path = pathlib.Path("data.txt")

    Sommige modulenamen zijn lang. Met as geef je een module een kortere naam. Dit is bij sommige modules, zoals matplotlib.pyplot, zelfs de standaard. 

    import matplotlib.pyplot as plt

x = [1, 2, 3]
y = [4, 5, 6]

plt.plot(x, y)
plt.show()

    Met from importeer je specifieke functies direct uit een module. Je hoeft dan niet steeds de modulenaam op te schrijven. 

    from math import pi, sin

result = sin(pi / 2)
print(result)
